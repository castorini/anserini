# Anserini Release Notes (v2.3.0)

+ **Release date:** August 25, 2026
+ **Lucene version:** Lucene 10.5.0

## Summary of Changes

+ Upgraded to Lucene 10.5.0 and refreshed affected effectiveness scores.
+ Externalized topics and qrels metadata to separate [`eval`](https://github.com/castorini/eval/) repo (with local "holding area").
+ Removed the `anserini-tools` submodule and its dependency from document-collection reproductions, with corresponding fixes to reproduction commands.
+ Moved metadata for prebuilt indexes to a separate [`prebuilt-indexes`](https://github.com/castorini/prebuilt-indexes/) repo.
+ Removed Lucene 8 compatibility from `SimpleSearcher` and stale cached topic entries.
